    Definitions and scope

    A correct pass is automatic Pass / reviewed Pass. A correct reject is automatic Fail / reviewed Fail. A false reject is automatic Fail / reviewed Pass. A false accept is automatic Pass / reviewed Fail. Unreviewed records are excluded from agreement and error-rate denominators.

    False reject rate = false rejects ÷ all reviewed Pass decisions. False accept rate = false accepts ÷ all reviewed Fail decisions. Review agreement = matching decisions ÷ reviewed decisions. A zero denominator is shown as a dash. The manual reviews are fictional reference labels, not independently established ground truth.

    Frames and review areas are drawn schematics. This project reviews saved result records; it does not run image recognition, inspect camera pixels, tune thresholds, or connect to MoldWatcher, KEYENCE, a PLC, or employer systems. Sample percentages demonstrate the calculations and do not describe production performance.
